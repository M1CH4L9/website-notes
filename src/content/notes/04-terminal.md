## Przykładowe polecenia
Kilka nieszkodliwych poleceń do pokazania wyglądu bloku Bash:

```bash
# Pokaż bieżący katalog
pwd

# Wyświetl listę plików
ls

# Sprawdź wersję Node.js
node --version
```

## Krótki opis
- `pwd` pokazuje bieżący katalog.
- `ls` wyświetla jego zawartość.
- Komentarz rozpoczyna się znakiem `#`.
